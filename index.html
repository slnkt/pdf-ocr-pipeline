Устройство

Из чего состоит сервис

API только принимает файлы и отдаёт результаты. Всю тяжёлую работу делает Worker, который берёт задачи из очереди в базе.

APIFastAPI с доступом по токену. Принимает PDF, отдаёт статус и результат
WorkerОтдельный процесс. Раз в 5 секунд проверяет очередь и разбирает документы
PostgreSQLОчередь задач и готовые результаты
Хранилище файловPDF на диске, имя файла совпадает с его отпечатком sha256
НейросетьQwen3-VL через OpenRouter или на своём GPU-сервере
СправочникСписок анализов с вариантами написания и единицами
Шаги

Пайплайн подробно

Приём
1

Клиент отправляет PDFapi/routes/extract.py

  • POST /v1/extract/async с файлом, request_id и токеном X-API-Token
  • API сохраняет PDF на диск под именем его отпечатка sha256
  • Клиент сразу получает job_id, ждать разбора не нужно
2

Проверка кэшаjobs/store.py

  • Файл уже разбирали: сразу возвращается готовый результат
  • Файл в работе: возвращается та же задача, без дубля
  • Иначе создаётся новая задача в статусе pending
3

Worker берёт задачуworker/main.py

  • Берёт самую старую задачу и переводит её в running
  • Несколько Worker'ов никогда не возьмут одну задачу
  • Задачи, зависшие дольше 120 минут, возвращаются в очередь
Чтение
4

Подготовка документаpipeline/document_prep.py

  • Проверка, что это настоящий PDF
  • Из PDF достаётся текстовый слой, он пригодится на шаге 7
  • Страницы превращаются в картинки 180 dpi, по одной на запрос. Другой режим: весь PDF одним запросом
5

Подсказки из PDFextraction/pdf_ref_hint.py

У Инвитро и ХромсистемсЛаб нормы нарисованы над цветными шкалами, и нейросеть путает строки. Код сам находит нормы по координатам в PDF и после ответа подменяет ими нормы нейросети.

Работает только в постраничном режиме и пока только для этих двух лабораторий.

6

Запрос в нейросетьpipeline/vlm_inference.py

  • По запросу на страницу, одновременно до двух
  • В запросе: промпт с правилами, картинка и жёсткая схема ответа
  • Ответы всех страниц склеиваются в один

Ошибка на любой странице переводит весь документ в failed

Проверка
7

Фильтр выдумокextraction/validate.py

Строка выбрасывается, если в ней нет названия или значения, если это служебный текст («метод», «пациент», «страница») или если её числа и названия нет в тексте PDF.

У сканов нет текстового слоя, поэтому для них проверка на выдумки не работает

8

Приведение к справочникуextraction/name_normalizer.py

  • Заголовки разделов вроде «Биохимия крови» выбрасываются
  • Названия заменяются каноническими из справочника
  • Лишние единицы у индексов и соотношений стираются
9

Нормализацияextraction/post_process.py

  • Значения: 7,50 → 7.5, флаги (H), (L) и стрелки убираются
  • Нормы: 0,0 - 5,0 → 0-5, «менее 200» → <200
  • Нормы по полу или возрасту переносятся в комментарий
10

Удаление дублейextraction/post_process.py

Одинаковые название, значение и единица считаются дублем. Из пары остаётся более полная запись, а комментарии и номера страниц объединяются, чтобы норма, разорванная переносом страницы, собралась обратно.

11

Сохранение и выдачаjobs/store.py

  • Результат пишется в базу, задача получает статус done
  • Клиент опрашивает GET /v1/extract/{job_id} до готовности
  • В ответе: анализы, данные пациента, лаборатория, дата и оценка качества разбора
Промпт

Что получает нейросеть

Промпт собирается в коде из шаблона и уходит с каждой страницей. Около 27 тысяч символов, большую часть занимает список названий из справочника.

Модель
Qwen3-VL
Параметры
temperature 0, до 4096 токенов ответа
Формат ответа
строгая JSON-схема
Версия промпта
v29

Из чего состоит запрос

  • Системный промпт с правилами на русском
  • Короткая просьба: «Извлеки данные… Ответь сразу JSON.»
  • Картинка страницы
  • Схема ответа: пациент, дата, лаборатория, анализы, самооценка качества

Главные правила

  • Все поля брать из одной строки таблицы, не от соседней
  • Знаки < и > сохранять, флаги убирать
  • В норму класть один диапазон, сложные нормы в комментарий
  • Заголовки разделов и прошлые результаты не считать анализами
  • Не путать похожие: MCV и MPV, B2 и B12, RDW-CV и RDW-SD
Справочник

Справочник маркеров

Используется трижды: как подсказка в промпте, для проверки на выдумки и для приведения названий к единому виду.

290анализов
869вариантов написания
29без единиц по природе
142без внутреннего ID

Что хранится по анализу

  • Каноническое название, оно попадает в ответ
  • Варианты написания: «АлАТ», «ALT», «АЛТ»
  • Единицы измерения или пометка, что их не бывает
  • Внутренний ID анализа в Bioniq

Как находится пара

  • Название чистится: регистр, ё/е, скобки, похожие буквы
  • Точное совпадение с вариантом написания сразу даёт пару
  • Иначе считается похожесть:
0,6 × общие слова + 0,4 × похожесть букв ≥ 0,60

Если два анализа набрали почти поровну, решают единицы измерения.
